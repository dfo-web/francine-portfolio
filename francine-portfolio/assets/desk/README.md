# Desk photographs

Keep this folder at `assets/desk/` beside the deployed `index.html`.

Replace or add these image files to update the desk photographs:

| Filename | Used for |
| --- | --- |
| `main-portrait.jpg` | The main portrait inside the computer screen. |
| `polaroid-1.jpg` | The first polaroid. |
| `polaroid-2.jpg` | The second polaroid. |

The included `main-portrait.jpg` preserves the current website portrait. Replace it with your own JPEG photograph using the same filename. JPEG files may be exported as `.jpg` or `.jpeg`; rename the deployed file to exactly `main-portrait.jpg`, `polaroid-1.jpg`, or `polaroid-2.jpg` so the website can find it. Browsers read the JPEG encoding from the file itself.

The included `polaroid-1.jpg` and `polaroid-2.jpg` contain placeholder artwork; replace them with your photographs using the same filenames. Their vector originals, `polaroid-1.svg` and `polaroid-2.svg`, are also included, and the website keeps embedded vector placeholders as fallbacks if a JPEG is unavailable. The main portrait also has the website's embedded image as a fallback.

Use a portrait-oriented main photograph and square or near-square polaroid photographs. The frames crop photographs to fit without stretching them. Optimized photographs around 1200–1600 pixels wide are sufficient for these frames.

Deploy `index.html` and the complete `assets` folder together, preserving the folder and filename capitalization. No code changes are needed when replacing these photographs.
